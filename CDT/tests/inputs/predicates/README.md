# Robust predicate test fixtures sources

Data: *Automatic Generation of Staged Geometric Predicates* (Nanevski,
Blelloch, Harper, ICFP 2001), published at
https://www.cs.cmu.edu/afs/cs/project/pscico/pscico/src/arithmetic/compiler1/test/.

Copies: `test/fixtures` of
[mourner/robust-predicates](https://github.com/mourner/robust-predicates)
(public domain, Unlicense). Only file names changed (`insphere.2d` is the
`incircle` case).
